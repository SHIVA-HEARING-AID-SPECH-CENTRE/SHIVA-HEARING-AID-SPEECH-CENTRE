SHIVA Hearing Aid & Speech Centre — Website Package

FILES
- index.html: Main responsive website
- styles.css: Website styling
- images/logo.svg: Editable vector logo concept
- images/hero-clinic.svg: Hero illustration
- images/hearing-aid-illustration.svg: Hearing aid illustration
- images/speech-care-illustration.svg: Communication illustration

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser (Chrome recommended).

HOW TO PUBLISH
Upload these files to a static hosting provider, or use them as a design/content reference for Google Sites. Google Sites does not directly import a full HTML website ZIP; it must be rebuilt in the Google Sites editor.

PLEASE VERIFY BEFORE PUBLISHING
- Exact street address and opening hours
- Phone / WhatsApp number
- Current brands, stock, repair services and speech therapy availability
- Professional credentials and any claims about services

This is a starter template. Illustrations are original vector graphics, not photographs of the actual clinic or products. The website makes no unverified claims about qualifications or service availability.
